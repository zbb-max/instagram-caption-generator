# Instagram Caption Generator

A beautiful, responsive web app that generates creative Instagram captions based on your keywords.

## Features

- Generate 6 unique Instagram captions instantly
- One-click copy to clipboard
- Mobile-first responsive design
- SEO optimized for Google
- No backend required - pure frontend

## Quick Deploy to Vercel

### Option 1: One-Click Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/instagram-caption-generator)

### Option 2: Via Vercel CLI

```bash
# Install Vercel CLI
npm i -g vercel

# Login to Vercel
vercel login

# Deploy
vercel
```

## Local Development

Simply open `index.html` in your browser, or use any local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve

# Using PHP
php -S localhost:8000
```

## Usage

1. Enter any keyword (e.g., "beach sunset", "friends party")
2. Click "Generate Captions"
3. Copy your favorite caption with one click

## Tech Stack

- Pure HTML, CSS, JavaScript
- Google Fonts (Inter, Outfit)
- No external dependencies
